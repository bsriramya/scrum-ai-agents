# Domain glossary (Product Owner)

Team-specific meanings. Keep this current — this is the source of truth for terms used in
stories and acceptance criteria.

| Term | Meaning |
|------|---------|
| **Returning customer** | A logged-in user with at least one prior completed order. |
| **Saved payment** | A tokenised card stored on file (never the raw card number). |
| **Checkout** | The flow from cart review to order confirmation. |
| **DoR** | Definition of Ready — see `definition-of-ready.md`. |
| **DoD** | Definition of Done — the team's completion checklist. |
| **WIP** | Work in progress. |
| **PII** | Personally identifiable information. |

> Add rows as the product evolves. When a story uses a term not listed here, add it (or
> flag it) rather than guessing its meaning.
