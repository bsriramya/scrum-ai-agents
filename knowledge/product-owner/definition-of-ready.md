# Definition of Ready (DoR)

A story is **Ready** to enter a sprint only when all of the following are true. The
Acceptance Criteria Writer uses this as the final check.

- [ ] Written as *"As a <role>, I want <goal> so that <benefit>."*
- [ ] Business value / benefit is clear.
- [ ] Acceptance criteria exist and are testable (Given/When/Then).
- [ ] Dependencies are identified (services, data, other teams).
- [ ] No open questions blocking a start; assumptions are stated.
- [ ] Sized/estimable by the team.
- [ ] Non-functional needs noted where relevant (performance, security, compliance).
- [ ] UX/design attached if the story has a UI.

> If any box is unchecked, the story is **not** Ready — list the gaps rather than
> inventing answers.
